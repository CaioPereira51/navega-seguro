# Relatório técnico

## Tecnologias
Vue 3, Composition API, TypeScript, Vite, Vue Router, Lucide Vue Next e CSS responsivo. Não há backend.

## Funcionalidades implementadas
Landing page, cinco módulos, cinco perguntas por módulo, correção e explicação das respostas, progresso local, checklist local, simulador de phishing fictício, modo claro/escuro e página Sobre.

## Testes
Registrar aqui a saída real de `npm run build` e verificações manuais de rotas, responsividade, teclado e armazenamento local.

## Melhorias futuras
Adicionar testes automatizados, revisão editorial por especialistas, referências bibliográficas e validação com usuários reais.
