# Relatório de extensão — base

## Descrição
O NavegaSeguro é uma plataforma educativa aberta para ensinar segurança digital em linguagem simples, com módulos sobre senhas, golpes, privacidade, navegação e redes sociais.

## Objetivos e metas
Disponibilizar o conteúdo gratuitamente; implementar atividades interativas; preparar o recurso para uso comunitário; avaliar a compreensão com feedback real.

## Metodologia
Desenvolvimento incremental orientado por PDCA, com validação técnica e posterior avaliação com beneficiários.

## Resultados técnicos verificados
Preencher após executar e registrar os testes do projeto.

## Resultados sociais
Campos pendentes. Não preencher sem participação real, evidências e autorização.
