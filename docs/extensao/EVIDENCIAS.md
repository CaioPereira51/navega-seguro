# Evidências

Este documento deve ser preenchido somente com evidências reais.

- URL pública: pendente de publicação.
- URL do repositório: pendente de definição.
- Data de publicação: pendente.
- Capturas de tela: inserir após a publicação.
- Evidências dos testes: inserir logs e resultados reais.
- Disponibilização para a comunidade: registrar data, canal e alcance efetivamente realizados.
- Feedback de beneficiários e instituição parceira: inserir apenas depoimentos autorizados e verificáveis.
